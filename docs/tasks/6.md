# AI-enabled pipeline
Ultimately, I want to have an LLM-enabled reasoning pipeline in the app, using Langgraph. The idea is that on schedule, an LLM can be prompted to do either a technical, data-driven, analysis, or a more of a real-world, semantic analysis of any market, and reason about the likelihood it will resolve to yes or no. THe details of how it does both of these things is for the future, but this task is just to scaffold up the LLM reasoning chain using Langgraph.
