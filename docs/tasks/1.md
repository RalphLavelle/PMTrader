# Node/TypeScript app
Create a Node app, with TypeScript, to integrate with the Jupiter predict platform (see the @docs/Jupiter folder for more info). This will be an app for participateing in binary prediction markets on Solana, allowing us to trade on the outcomes of real-world events. Docs are here: https://developers.jup.ag/docs/prediction

## Back end
The back end is obviously what directly connects to the Jupiter API, making trades, opening and closing positions, etc.

## Front end
The front end is just to allow me to interact with the back end, get reports, and occasionally make interventions. To start with though I'll only need to see what trades have happened. Leave the human in the loop stuff till later. Use Angular to make the front end, with Less as the CSS-preprocessor. Avoid using Tailwind or any 3rd party libraries for the time being.
