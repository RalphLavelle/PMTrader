# Saving runs to a database
For each run that runs, save the run to a database. The details to connect to the MongoDB can be fond in the .env file. The database is PRMTrade, and the collection is runs. WIre up whatever needs to be done to save a run into the db, then call a run and check that it's successfully saved to the db. Remove whatever code there is to save runs elsewhere, either in memory or to a file.
